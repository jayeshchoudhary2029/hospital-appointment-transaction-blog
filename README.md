# Hospital Appointment System — DBMS Technical Blog

A browser-based educational mini-project for the DBMS question:
“Analyze how transaction management can be used in a hospital appointment system to prevent two patients from receiving the same doctor appointment slot.”

## Run
Open `index.html` in Chrome, Edge or Firefox.

## Blog sections
1. The Problem
2. Transaction Basics
3. Conflicting Operations
4. Double-Booking Anomaly
5. Serializability
6. Locking / Concurrency Control
7. Interactive Transaction Demo
8. System Flow
9. Real-world applications
10. Conclusion and references

## Interactive demo
Keep T1 and T2 on Dr. Sharma at 10:00 AM.
- Run unsafe schedule: demonstrates the anomaly.
- Reset.
- Run with locking: demonstrates T1 → T2 and rejection of the second booking.

## Technology
HTML5, CSS3 and JavaScript. The project is an educational frontend simulation, not a production hospital database.
